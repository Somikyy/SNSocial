[SIZE=5][B]В чём проблема[/B][/SIZE]

Каждому серверу нужен свой Telegram-канал и группа VK — там анонсы, там комьюнити, там жизнь между заходами. Игроки подписываются охотнее, когда за это что-то дают. А чем это сделать?

[LIST]
[*]Единственное живое решение — платное: [B]599.99 ₽[/B] (зимой 2026 оно стоило ~250 ₽ — цену подняли).
[*]Бесплатный fmSocialReward брошен автором [B]в день релиза в 2023 году[/B] и подписку не проверяет вообще — только привязку в чужой базе.
[*]На вопрос «как выдать награду за привязку Telegram» комьюнити в июне 2026 отвечало дословно: [B]«Только изменив код плагина»[/B].
[/LIST]

SNSocial закрывает это бесплатно и с открытым кодом.


[SIZE=5][B]Что делает[/B][/SIZE]

[LIST]
[*][B]Привязка Telegram в один клик[/B]: игрок пишет /snsocial link telegram, получает кликабельную ссылку на бота с кодом внутри — нажал, отправил, привязан.
[*][B]Привязка VK[/B]: код отправляется в сообщения группы, бот отвечает и привязывает.
[*][B]Проверка подписки через официальные API[/B]: Telegram getChatMember, VK groups.isMember. Никаких «скинь скриншот».
[*][B]Награды двух типов[/B]: разовые за подписку и периодические (каждые N часов, пока подписан). Награда — любые консольные команды.
[*][B]Требование обеих сетей сразу[/B]: отдельная награда за «подписан и в ТГ, и в VK».
[*][B]GUI[/B] со статусом каждой награды: доступна, получена, нужна привязка, кулдаун.
[*][B]PlaceholderAPI[/B]: %snsocial_telegram_subscribed%, %snsocial_available% и другие.
[*][B]SQLite или MySQL[/B] — драйверы уже встроены в Paper, ставить ничего не нужно.
[/LIST]


[SIZE=5][B]Антиабуз — то, ради чего это писалось[/B][/SIZE]

[LIST]
[*][B]Отписался — награда откатывается.[/B] Плагин перепроверяет подписки по интервалу и при входе; при отписке выполняются revoke-команды.
[*][B]Подписался → забрал → отписался → подписался снова?[/B] Не сработает: откат запоминается в базе, и без reclaimable: true награда больше не выдаётся.
[*][B]Десять твинков на один аккаунт?[/B] Нет: один Telegram/VK-аккаунт привязывается только к одному игроку.
[*][B]Отвязался и привязался заново?[/B] История наград переживает отвязку.
[*][B]API Telegram упал в момент проверки?[/B] Игрок не пострадает: откат происходит только по подтверждённой отписке, никогда — по ошибке сети.
[/LIST]


[SIZE=5][B]Как это выглядит для игрока[/B][/SIZE]

[CODE]/snsocial link telegram
SNSocial » Твой код: KP7M2X. Нажми сюда, чтобы открыть бота, и отправь ему код.

(в Telegram, один клик)  → Готово! Аккаунт привязан к игроку Somikyy.

SNSocial » Аккаунт привязан! Смотри награды: /snsocial
SNSocial » Награда получена: Подписка на Telegram![/CODE]


[SIZE=5][B]Переезд с fmSocialReward — одна команда[/B][/SIZE]

[CODE]/snsocial import fmsocialreward[/CODE]

Плагин читает config.yml старого плагина и помечает уже полученные награды, чтобы никто не забрал их второй раз. Переезд без дублей и без ручной работы.

[SIZE=5][B]Установка за 15 минут[/B][/SIZE]

[LIST=1]
[*]Кинь jar в plugins, запусти сервер — появится config.yml с подробными комментариями.
[*][B]Telegram[/B]: создай бота у @BotFather, токен в конфиг; добавь бота администратором канала (требование Telegram — иначе подписчиков не видно).
[*][B]VK[/B]: ключ сообщества с правами «управление» и «сообщения», включи Long Poll API и событие «Входящее сообщение».
[*]/snsocial reload — готово.
[/LIST]


[SIZE=5][B]Технические детали, которые обычно выясняются слишком поздно[/B][/SIZE]

[LIST]
[*]Работает на [B]1.20.1 – 26.2[/B]: только публичный Paper API, ни строчки NMS — мажорные обновления сервера плагин не ломают.
[*][B]Java 17+[/B] — старые сборки не выброшены за борт.
[*]Главный поток сервера не трогается вообще: вся сеть и база — в отдельных потоках. 0.00 мс на TPS.
[*]Ноль зависимостей: HTTP — из JDK, JSON — свой, драйверы БД — серверные. Jar лёгкий и читается глазами.
[*]81 офлайн-тест в CI на реальных форматах ответов Telegram/VK.
[/LIST]
