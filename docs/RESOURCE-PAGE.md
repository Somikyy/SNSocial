## Краткое описание (tagline)

> Выдаёт награды за подписку на твой Telegram-канал и группу VK. Отписался — награда
> откатывается. Бесплатно, с открытым кодом, там, где раньше было либо 600 ₽, либо мёртвый
> плагин 2023 года.

**Сокращённый вариант:**

> Награды за подписку на ТГК и VK-группу: проверка через официальные API, откат при отписке, GUI.

## Поддерживаемые версии Minecraft

**1.20.1 — 26.2.**

Собрано под `api-version: 1.20`, NMS не используется вообще, поэтому обновление сервера
плагин не ломает. Теги версий при публикации: 1.20, 1.21, 26.1, **26.2**.

---

## Поддерживаемые ядра

| Ядро | Статус |
|---|---|
| **Paper** | Основная платформа, 1.20.1+ |
| **Purpur и другие Paper-форки** | Работают: используется только публичный Paper API |
| **Folia** | Код написан на Folia-планировщиках, но флаг `folia-supported` пока `false` — честно, до реального теста |
| **Spigot** | Не поддерживается: используется Adventure API Paper |

---

## Минимальная версия Java

**Java 17.**

Осознанно ниже, чем у большинства современных плагинов: SNSocial должен работать и на
старых серверах 1.20.1, которых конкуренты лишились, подняв требования. На Java 21 и 25
работает без нареканий.

## Описание

Полный BB-код тела страницы — в [RESOURCE-PAGE.bbcode.txt](RESOURCE-PAGE.bbcode.txt).
Структура: проблема (рынок из платного за 600 ₽ и мёртвого бесплатного) → что делает
SNSocial → как выглядит для игрока → антиабуз → отличия от конкурентов → установка за
15 минут → импорт из fmSocialReward → открытый код.

## Команды и права

Отдельный BB-код блок — [RESOURCE-PAGE.commands.bbcode.txt](RESOURCE-PAGE.commands.bbcode.txt).

| Команда | Право | По умолчанию | Что делает |
|---|---|---|---|
| `/snsocial` | `snsocial.use` | у всех | GUI наград |
| `/snsocial link telegram\|vk` | `snsocial.use` | у всех | Получить код привязки |
| `/snsocial unlink telegram\|vk` | `snsocial.use` | у всех | Отвязать аккаунт (с подтверждением) |
| `/snsocial claim <id>` | `snsocial.use` | у всех | Забрать награду без GUI |
| `/snsocial status` | `snsocial.use` | у всех | Привязки и статусы подписок |
| `/snsocial check <игрок>` | `snsocial.admin` | op | Форс-перепроверка подписок игрока |
| `/snsocial info <игрок>` | `snsocial.admin` | op | Привязки и полученные награды игрока |
| `/snsocial reload` | `snsocial.admin` | op | Перезагрузка конфига без рестарта |
| `/snsocial import fmsocialreward` | `snsocial.admin` | op | Импорт данных из fmSocialReward |
| `/snsocial version` | `snsocial.admin` | op | Версия и проверка обновлений |

Алиасы команды: `/social`, `/sns`, `/снс`.
