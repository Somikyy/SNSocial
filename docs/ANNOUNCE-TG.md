🎁 **SNSocial — награды за подписку на ваш ТГК и группу VK**

Хотите «подпишись на канал — получи награду»? До сих пор выбор был такой: единственное живое
решение за 599.99 ₽, либо бесплатный плагин, брошенный автором в день релиза три года назад.
Вопрос «как выдать награду за привязку телеграма» комьюнити закрывало советом «только изменив
код плагина».

Теперь — бесплатно, с открытым кодом и с честной проверкой подписки.

💎 **Что делает:**

▫️ **Привязка в два клика:** для Telegram — кликабельная ссылка на бота, для VK — короткий код
в сообщения группы. Из игры, без танцев.
▫️ **Честная проверка подписки** через официальные API (getChatMember / groups.isMember) — не
«привязал и забыл», а реальное членство в канале и группе.
▫️ **Награды разовые и периодические** + GUI со списком и статусами.
▫️ **Антиабуз:** отписался — награда откатывается; отписался-переподписался — повторно не
фармится; один соцаккаунт = один игрок; твинки мимо.
▫️ **Плейсхолдеры PlaceholderAPI** — статусы подписки в любом меню или табе.
▫️ **Импорт из fmSocialReward** — переезд с мёртвого плагина одной командой.

⚙️ **Команды и права:**

/snsocial — GUI наград (snsocial.use)
/snsocial link telegram|vk — привязка (snsocial.use)
/snsocial import fmsocialreward — импорт (snsocial.admin)

📦 **Технически:** один jar без внешних зависимостей, SQLite/MySQL (драйверы поставляет Paper),
локали ru/en, полный самотест без сети. GPL-3.0, весь код открыт.

🕹 **Версии:** Paper/Purpur 1.20.1 — 26.2

Каждый сервер с SNSocial — это живой прирост подписчиков вашего канала. Поставили — напишите
в комментариях, сколько принесло за неделю: соберу кейсы.
