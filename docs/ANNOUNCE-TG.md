# Анонс SNSocial для Telegram-канала

Структура повторяет опубликованный пост SNAuthLink (05.08.2026):
строки с «>» — вставить цитатой (blockquote), таблицу команд — таблицей (Премиум),
жирное — Ctrl+B, ссылки прятать под «тык», эмодзи-маркеры пунктов — кастомные из набора канала.

---

🎁 **SNSocial — награды за подписку на ваш ТГК и группу VK**

> Хотите «подпишись на канал — получи награду»? Выбор был такой: единственное живое решение
> за 599.99 ₽ — либо бесплатный плагин, брошенный автором в день релиза три года назад.
> «Как выдать награду за привязку телеграма?» — «Только изменив код плагина».
> Теперь — бесплатно, с открытым кодом и с честной проверкой подписки.

💎 **Что делает**

> ⚪ **Привязка в два клика:** для Telegram — кликабельная ссылка на бота, для VK — короткий
> код в сообщения группы. Из игры, без танцев.
> ⚪ **Честная проверка подписки** через официальные API — не «привязал и забыл», а реальное
> членство в канале и группе, с перепроверкой.
> ⚪ **Награды разовые и периодические** + GUI со списком и статусами.
> ⚪ **Антиабуз:** отписался — награда откатывается; отписался-переподписался — повторно не
> фармится; один соцаккаунт = один игрок.
> ⚪ **Плейсхолдеры PlaceholderAPI** — статусы подписки в любом меню или табе.
> ⚪ **Импорт из fmSocialReward** — переезд с мёртвого плагина одной командой.

📈 **Растит именно ваш канал**

> Каждый сервер с SNSocial — живой прирост подписчиков вашего ТГК. Поставили — напишите,
> сколько принесло за неделю: соберу кейсы.
